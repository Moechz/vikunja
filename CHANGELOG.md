# Changelog

All notable user-visible changes to the Vikunja TOS application package.

## 2.8.0-1 — 2026-11-14

### Added
- First release. Vikunja (`vikunja/vikunja:2.8.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8123 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/vikunjadocker/`.
